## Running the pipeline

The scripts import each other, so the runnable copy is in **`rag_agent/`**.
The files in `Assignments/Task_N/` are copies of the outputs of each task.

```
cd rag_agent
python -m pip install numpy scikit-learn fastembed openai
python chunker.py                     # Task 2 -> chunks.json
python embedder.py build              # Task 3 -> vector_store/ (bge-small-en-v1.5)
python eval_retrieval.py              # retrieval check (Hit@k, MRR)
python matcher.py "task text" -n 5    # Task 4
python solver.py --tasks ../Assignments/missing_code.json   # Task 5 (needs OPENAI_API_KEY in .env)
python solver.py --restore            # put the stubs back
```
